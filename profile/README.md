# efficiency-learning

efficiency-learning is a GitHub organization for research code focused on efficient learning, data selection, and prototype selection for modern machine learning systems.

## Projects

- [banditsubmod](https://github.com/efficiency-learning/banditsubmod) — NeurIPS 2025 code for bandit-guided submodular curriculum learning and adaptive subset selection.
- [UniPROT](https://github.com/efficiency-learning/UniPROT) — AISTATS 2026 code for uniform prototype selection via partial optimal transport with submodular guarantees.
- [PartitionSEL](https://github.com/efficiency-learning/PartitionSEL) — ICML 2026 code for partition-matroid-constrained minibatch selection for language model fine-tuning.

## Focus areas

- Efficient training and fine-tuning
- Data subset and minibatch selection
- Prototype selection and optimal transport
- Vision and language model experiments
